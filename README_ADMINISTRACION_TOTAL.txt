VERSION ADMINISTRABLE - UN SOLO DOCENTE

Esta versión mantiene el sistema anterior de un solo docente, pero ahora permite
administrar desde el panel:

- Cambiar el nombre visible del profesor.
- Borrar todos los grupos y crear grupos nuevos.
- Crear y borrar grupos individualmente.
- Borrar todos los estudiantes y registrarlos nuevamente.
- Crear estudiantes manualmente.
- Borrar estudiantes individualmente.
- Reiniciar profesor + grupos + estudiantes + clases + asistencias.

IMPORTANTE SOBRE EL PROFESOR
El botón de reinicio NO elimina tu cuenta de acceso de Supabase Authentication.
Eso es intencional: si se eliminara esa cuenta ya no podrías entrar al panel.
Lo que se borra y vuelve a crear es el NOMBRE VISIBLE DEL PROFESOR.

PASOS
1. En Supabase > SQL Editor abre ADMINISTRACION_TOTAL.sql.
2. Ejecuta todo el archivo con Run.
3. Sube a GitHub Pages los archivos de este ZIP, reemplazando los anteriores.
4. Actualiza la página con Ctrl + F5.
5. Ingresa al panel docente.
6. En "Administración del sistema" podrás borrar y crear nuevamente
   profesor, grupos y estudiantes.

La cuenta de acceso docente y la contraseña siguen siendo las mismas que ya tienes.
