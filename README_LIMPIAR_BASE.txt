BOTÓN LIMPIAR TODA LA BASE

1. Antes de usar el botón por primera vez, abre supabase.sql.
2. Ejecuta en Supabase SQL Editor el bloque final llamado:
   LIMPIEZA TOTAL DEL SISTEMA.
3. Luego sube estos archivos actualizados a GitHub Pages.

El botón está en el panel docente.
Tiene doble confirmación:
- Confirmar el aviso.
- Escribir exactamente: LIMPIAR TODO

Elimina:
- todas las asistencias;
- todos los estudiantes registrados;
- todas las sesiones/clases (por tanto, los grupos/clases almacenados).

NO elimina las tablas ni su estructura.
